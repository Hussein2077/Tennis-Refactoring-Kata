# Tennis Game Kata (Dart)

Implementation and refactoring of the Tennis Game Kata in Dart, featuring a clean domain-driven architecture for `TennisGame1`.

## Features
- **TennisGame1**: Refactored with clean-code principles, explicit scoring states, and idiomatic Dart.
- **TennisGame1_Refactoring_Steps.md**: Complete step-by-step documentation detailing all refactoring decisions.
- **Unit Tests**: Full test suite covering all scoring scenarios (regular, ties, advantage, and win conditions).

## Running Tests
To fetch dependencies and run the tests:
```bash
dart pub get
dart test
```
